# Home Weather Station
The "Home weather station" is a costom weatherstation designed to be put on a post in your backyard
-
## The Readings/Sensors
We will have a multitude of sensors including but not limited to:

### 1.BME280 Temp/Humidity/Pressure Sensor
This sensor will measure Degrees (Fahrenheit Freedom Units), Humidity (Percentage), And Pressure (inHG)
### 2.Anemometer (reed switch)
This uses a hall-effect sensor and half spheres to measure wind speed
### 3. Wind Vane (resistor ladder)	
This will measure the wind direction using areodynamics 
### 4. Tipping Bucket Rain Gauge	
This will calculate the hourly precipitation rates (in)
### 5. PMS5003 PM2.5/PM10 Sensor	
This will measure Air Qiality (AQI) using lasers
### 6. VEML6075 UV Sensor	
This will calculate the UV Index at that time
### 7. AS3935 Lightning Sensor Module	
This can calculate the distance of storms using lighting 
### 8. DS18B20 Waterproof Temp Probe	
This is for detecting the ground temprature (Fahrenheit) and it can calculate if the rain will turn to ice on the ground
### 9. PoE RTSP/ONVIF Outdoor Camera (1080p)
It will record in 1080p and H.264 codec and this is to send to the local weather meterologist
